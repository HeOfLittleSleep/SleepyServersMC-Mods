## Preamble

a collection of forge installers used for the various iterations of our minecraft servers. you can find them in this branch, and this document will attempt to explain which server uses which forge version.


## MC-Public-v5

the (hopefully last) 1.12.2 server. this one used `forge-1.12.2-14.23.5.2860-installer.jar`, but it had been updated over the course of the server's lifetime, so `forge-1.12.2-14.23.5.2859-installer.jar` may be necessary when trying to run an older backup of this server


## MC-Public-v6

this server uses `forge-1.20.1-47.4.0-installer.jar`


## MC-Public-v6.1

this server uses `forge-1.20.1-47.4.10-installer.jar`
